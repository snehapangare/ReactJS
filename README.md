# 🧍‍♀️ React Person Info Display

A simple **React app** that displays a list of people.
When you click on a person’s name, their detailed information (name, age, and city) appears below the list.

## 🚀 Features

* Displays a list of people using **React state and props**
* Highlights the **selected person** with a background color
* Dynamically shows **detailed info** (Name, Age, City) when clicked
* Uses **React Hooks** (`useState`) for state management
* Styled with simple **inline CSS**

## 🧩 Technologies Used

* React (Functional Components)
* useState Hook
* Inline CSS Styling

## 🧠 Concepts Used

* **Conditional Rendering:** To show person details only when a person is selected
* **Array Mapping:** To display all names dynamically
* **State Management:** Using `useState()` to handle selected person
